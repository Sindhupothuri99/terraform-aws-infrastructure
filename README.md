# AWS Infrastructure Automation Using Terraform

## Project Overview
Automated AWS infrastructure provisioning using Terraform.

## Technologies
- AWS
- Terraform
- Git
- GitHub
- Ubuntu
- Nginx

## AWS Services
- VPC
- Public Subnet
- Private Subnet
- Internet Gateway
- Route Table
- Security Group
- EC2

## Implementation
1. Configured AWS CLI using IAM credentials.
2. Created VPC using Terraform.
3. Created public and private subnets.
4. Configured Internet Gateway.
5. Configured public route table.
6. Created security group.
7. Launched Ubuntu EC2 instance.
8. Installed Nginx automatically.
9. Hosted a website on EC2.
